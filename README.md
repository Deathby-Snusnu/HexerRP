# HexerRP

RP-Addon fuer Hexenmeister mit Zaubertexten und seltenem Ambient-RP.

## Besonderheiten
- Deutsch, Englisch, Franzoesisch
- Gesprochene Zeilen und `*...*`-Aktionen (`/me`)
- `%s` = aktuelles Ziel, `%p` = aktueller Daemonenbegleiter
- Ambient-Stufen: MURMUR, DISTURBED, OUTBURST
- lange zufaellige Intervalle, standardmaessig ausserhalb des Kampfes

## Befehle
`/wrp help`, `/wrp list`, `/wrp status`
`/wrp language deDE|enUS|frFR`
`/wrp ambient on|off`
`/wrp ambient test murmur|disturbed|outburst`
`/wrp ambient chance 0-100`
`/wrp ambient interval MIN MAX`
`/wrp ambient combat on|off`
